# 模型广场币种展示

在「系统设置 → 功能设置 → 模型广场」配置客户折后价币种、官方参考价默认币种、站内额度参考价值，以及 USD/CNY 展示参考汇率。所有字段只影响广场展示，不修改渠道原价、分组或专属倍率、充值、订阅和实际扣费。

## 默认与换算

未配置时，1 站内额度的参考价值为 1 USD，客户价和官方价都显示美元，保持原有美元价卡的数值。USD/CNY 展示参考汇率默认 7.00，可改为站点采用的值；该值是固定参考值，不是实时外汇报价。

客户参考价 = 原价 × 生效倍率 × 每额度参考价值，再在参考价值币种和客户展示币种不同时转换。实际采用分时、阶梯、图片／视频独立倍率等现有规则。官方参考价来源为美元目录，显示人民币时乘展示汇率。

例如站点按 ¥1 获得 1 额度运营，可将每额度参考价值设为 1 CNY，客户价币种设为 CNY。账面单价 4.5、分组倍率 0.5 时显示 ¥2.25；不会再乘 7。充值赠送、券和手续费会影响用户购入额度的成本，参考值不代表每位用户实际支付成本。

如果站点按真实美元运营，保持默认 1 USD 即可。无需调整充值倍率来改变广场展示。

## 官方参考价覆盖规则

官方价可以按平台 ID 或模型 ID 单独指定 USD／CNY。模型规则优先于平台规则，其余使用官方默认币种。ID 完整匹配，忽略大小写及首尾空白；不支持通配符，没有预置国家、站点或供应商名单。混合分组使用每个模型实际返回的平台字段。

例如保留官方默认 USD，再添加平台 `deepseek` → CNY，该平台官方价显示人民币，其他平台仍显示美元。也可为特定完整模型 ID 设为 USD，覆盖其平台规则。其余平台由站点自行选择，系统不自动推断“国产模型”。

## 兼容与回滚

设置存储在已有 settings 中：`model_plaza_usd_to_cny_rate` 和 `model_plaza_currency`，不需要数据库迁移。旧客户端省略新字段时保留配置；旧前端忽略广场新增元数据。新前端遇到缺少元数据的旧后端时保留原始数值，并明确区分站内额度和官方 USD。

回退应用代码恢复旧展示，新增设置可以保留。修改配置后刷新广场核对金额符号、列标题、参考汇率和额度价值；真实扣费验证应独立进行。
