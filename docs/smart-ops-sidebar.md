# 智能运维侧边栏展示

管理员在「系统设置 → 功能开关 → 智能运维侧边栏」中选择要展示的入口，点击系统设置的保存按钮后生效。支持逐项切换、全部显示和全部隐藏。全部隐藏时收起整个侧边栏分组，功能搜索也不再列出被隐藏的菜单入口。

这是站点级配置，对所有管理员生效，不是每位管理员的个人偏好。只控制侧边栏和基于该菜单的功能搜索；页面内导航、直接地址访问、后台任务及功能自身配置不受影响。请求采集等已有启用条件仍然有效，选择展示不能替代启用功能。

新安装或尚未保存侧边栏选择的站点默认展示 6 个入口：自动配置、优先调度、利润运维、质量运维、凭证运营、鹈鹕测智。抽奖管理、渠道运维、受控实验、账号运维、凭证守护、分组缓存测试、请求采集、打票流程默认隐藏，管理员可在此面板手动开启。

配置通过管理员设置 API 的 `smart_ops_hidden_menu_items` 字符串数组保存，数组元素为菜单路径。未配置或存储值无效时使用上述默认选择；显式保存空数组仍表示全部显示。已保存的自定义选择保持不变，旧客户端省略该字段不会清空已保存的配置。使用现有 settings 存储，不新增数据库迁移。未知路径保留以兼容后续版本，但只会对智能运维分组内的现有路径生效。回退到仍支持此设置的旧版时，已保存选择继续生效，未保存配置可能恢复为全部显示；回退到不支持此设置的版本时，旧界面忽略配置，重新升级后恢复。

新功能提示 ID 为 `smart-ops-sidebar-visibility-initial-announcement`，展示在面板标题旁，沿用当前浏览器、当前管理员的新功能提示关闭机制。

## 待验收

- 新安装或未保存过侧边栏选择时显示上述 6 项；关闭单项或开启其他入口并保存后，菜单和功能搜索同步更新，刷新后从服务端重新读取。
- 已保存的自定义选择和显式全部显示不因升级被覆盖；前端初始状态及缺少该设置字段时使用同一组 6 项默认值。
- 全部隐藏并保存后智能运维分组消失；系统设置入口始终保留，可重新全部显示。
- 请求采集未启用时，即使选择展示，也不出现菜单；隐藏菜单不改变其运行开关。
- 旧客户端保存其他设置不清空菜单选择；中英文文案、窄屏排版和新功能提示关闭行为正常。
