# 智能运维侧边栏展示

管理员在「系统设置 → 功能开关 → 智能运维侧边栏」中选择要展示的入口，点击系统设置的保存按钮后生效。支持逐项切换、全部显示和全部隐藏。全部隐藏时收起整个侧边栏分组，功能搜索也不再列出被隐藏的菜单入口。

这是站点级配置，对所有管理员生效，不是每位管理员的个人偏好。只控制侧边栏和基于该菜单的功能搜索；页面内导航、直接地址访问、后台任务及功能自身配置不受影响。请求采集等已有启用条件仍然有效，选择展示不能替代启用功能。

配置通过管理员设置 API 的 `smart_ops_hidden_menu_items` 字符串数组保存，数组元素为菜单路径。缺省或空数组表示不主动隐藏任何入口；旧客户端省略该字段不会清空已保存的配置。使用现有 settings 存储，不新增数据库迁移。未知路径保留以兼容后续版本，但只会对智能运维分组内的现有路径生效。回退旧版后旧界面忽略此配置，重新升级后恢复。

新功能提示 ID 为 `smart-ops-sidebar-visibility-initial-announcement`，展示在面板标题旁，沿用当前浏览器、当前管理员的新功能提示关闭机制。

## 待验收

- 初次升级保持原有菜单，关闭单项并保存后菜单和功能搜索同步减少；刷新后从服务端重新读取。
- 全部隐藏并保存后智能运维分组消失；系统设置入口始终保留，可重新全部显示。
- 请求采集未启用时，即使选择展示，也不出现菜单；隐藏菜单不改变其运行开关。
- 旧客户端保存其他设置不清空菜单选择；中英文文案、窄屏排版和新功能提示关闭行为正常。
