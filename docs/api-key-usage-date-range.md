# API 密钥按日期统计用量

在「API 密钥」列表的分组、状态筛选旁选择「用量日期」，设置开始日期和结束日期后点击「应用」。支持现有日期控件的快捷范围及自定义日期。

- 默认显示包含今天的最近 30 个日历日。
- 自定义范围应用后，各 Key 的「近30天」金额切换为「所选时段」金额；「今日」金额保持独立。
- 金额按使用记录中的实际扣费 `actual_cost` 汇总，保留四位小数。统计基于仍保留的使用记录。
- 开始日和结束日均包含全天，使用浏览器时区；后端按 `[开始日 00:00, 结束日次日 00:00)` 查询，夏令时切换按日历计算。
- 快捷范围只提供自然日选项，不提供「近24小时」；自定义昨天至今天显示实际日期范围。
- 翻页、搜索、分组及状态筛选沿用已选择的日期。重新进入页面时恢复默认范围。
- 快速切换日期会取消旧请求并忽略其晚到结果；查询失败时显示「—」，点击页面刷新按钮重试。

## 接口

扩展现有 `POST /api/v1/usage/dashboard/api-keys-usage`，仍只返回当前用户拥有的 Key：

```json
{
  "api_key_ids": [7, 8],
  "start_date": "2026-11-01",
  "end_date": "2026-11-03",
  "timezone": "Asia/Shanghai"
}
```

`start_date` 和 `end_date` 必须同时传入，格式为 `YYYY-MM-DD`，开始日期应早于或等于结束日期。不传日期的旧客户端继续使用原有滚动 30 天统计。响应中的 `total_actual_cost` 为查询范围内实际扣费，`today_actual_cost` 继续使用既有的服务端当日口径。无需数据库迁移。

管理员日期选择旁登记的新功能提示 ID 为 `api-key-usage-date-range-initial-announcement`，关闭状态沿用按管理员、按浏览器保存的提示机制。
