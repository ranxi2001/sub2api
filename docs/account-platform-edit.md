# 编辑现有账号的平台

管理员进入「账号管理 → 编辑账号」后，可在表单顶部选择平台。

- API Key 账号可切换到支持 API Key 的平台，保留原密钥和 Base URL。请确认上游支持目标平台协议；需要时修改地址或输入新密钥。
- Google 服务账号（`service_account`）可在 Gemini 与 Anthropic Vertex 之间切换，保留服务账号凭证、项目和区域。
- OAuth、Setup Token、Bedrock、Upstream 与影子账号的授权绑定平台。选择项显示当前平台与原因；跨平台使用需新建并授权目标平台账号。此次操作保持账号类型。

切换平台时，表单重置模型映射、平台专属选项与旧平台的模型探测状态。名称、备注、代理、并发、倍率、到期时间与账号配额沿用；分组仅保留目标平台或组合分组。保存前可调整目标平台设置和分组，取消或重新打开会恢复已保存配置。模型同步与用量刷新应在保存平台变更后执行。

`PUT /api/v1/admin/accounts/:id` 新增可选的 `platform` 字段；省略或传入原平台沿用原编辑规则。平台修改和最终分组绑定在同一事务中提交，未知平台、不兼容凭证类型、影子依赖及不兼容的显式分组在写入前校验。API Key 密钥继续由服务端保留，响应保持脱敏。历史用量与账号 ID 保留；无需数据库迁移。

新功能提示 ID：`account-edit-platform-initial-announcement`。唯一入口为编辑账号的平台标签；关闭状态按现有机制保存在当前浏览器、当前管理员的本地存储中。
