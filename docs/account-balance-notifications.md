# 单账号余额不足通知

在「智能运维 → 账号运维 → 设置」的账号列表中，每个 API Key 账号都有「请求余额不足通知」开关。关闭后，该账号请求返回余额不足时，不再发送邮件或机器人通知；发送队列在每次投递前重新检查开关。已经发送的通知无法撤回。

余额阈值及余额恢复通知仍由原来的阈值规则控制。需要完全关闭某个账号的余额提醒时，同时关闭它的余额阈值规则与请求余额不足通知。其他账号、周额度提醒和账号调度不受这个开关影响。

管理 API：`PUT /api/v1/admin/account-ops/accounts/:id/balance-notification`，请求体为 `{"enabled":false}`，恢复时传 `true`。接口使用现有管理员认证并校验目标账号，在配置锁内仅更新该账号的请求余额不足通知设置。返回更新后的账号运维配置。

配置新增 `balance_low_disabled_account_ids`，缺省为空，沿用全局 `balance_low` 开关；单账号开启不能覆盖全局关闭。旧客户端保存未包含此字段的完整配置时，服务端保留已保存的单账号设置。无数据库迁移；回滚到不支持此字段的旧二进制后，单账号屏蔽不再生效。
