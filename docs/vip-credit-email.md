# VIP 自动垫付成功邮件通知

开发中：管理员可选择在每次成功发行 VIP 自动垫付后通知该 VIP 用户邮箱，默认关闭。

通知绑定已提交账本，保存设置、未发行、拒绝准入和回滚不发送。邮件通过独立持久化 outbox 重试；SMTP 接受与数据库确认之间崩溃可能重发，不保证端到端 exactly-once。完整验收和 CI 证据见本功能 Draft PR。

发行时快照该 VIP 账号邮箱；之后关闭通知只影响后续发行，已经提交的通知继续重试。空收件人不会使用管理员邮箱替代，会保留失败回执供修正排查。邮件失败不回滚已提交垫付；回执入库失败则明确返回事务错误，连同扣款/发行原子回滚，沿用账本、审计和缓存回执的错误策略。

后台 worker 使用一个独立的 PostgreSQL 连接池（最多一个连接），持有回执行锁直到发送与确认完成，避免与计费/模板读取连接池竞争。关闭 worker 会等待当前发送结束，再关闭其连接池；SMTP 沿用现有有界连接/读写超时。新增 `340_vip_auto_credit_email.sql` 只添加默认 false 的字段和 outbox，不回填历史通知。回退二进制不会删除新增列、表或待通知。

连接获取、BEGIN 和领取使用短超时；成功领取后撤销该超时对事务的取消，避免发信途中锁自动过期。此链路由 outbox 单独负责去重和发送确认，避免正常停机取消后，通用邮件服务的额外标记写入将已接受的邮件误记为失败。
