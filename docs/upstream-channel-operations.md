# 渠道运维

服务商管理与 URL 运维视图用途不同。接入服务商后，在「利润运维」可查看该服务商的渠道、钱包读数及最后观察时间。导入的 Key 通过其服务商来源建立归属，而不是靠 URL 或同名渠道匹配。钱包可能有外部调用，不能直接用作本站成本。关于改绑、升级和隔离测试，见[利润运维说明](profit-operations.md#服务商对账与隔离试用)。
