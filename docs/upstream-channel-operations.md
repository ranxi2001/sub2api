# 渠道运维

服务商管理与 URL 运维视图用途不同。在「利润运维」登记服务商后，原来按同一站点网址统计、又没有其他明确归属的请求会归入它的渠道，无需重新导入 Key；手动解绑后，唯一站点仍可回到该服务商。打开本页会自动刷新一次已保存登录态的服务商，更新卡片上的「今日消费」（上游钱包消费，可能含非本站支出）。利润页按所选时段另存窗口快照，不会用历史区间覆盖这张今日卡片。未绑定的渠道仍用倍率估算。见[利润运维说明](profit-operations.md#财务口径)。
