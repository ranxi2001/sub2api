# 优先调度

入口：`/admin/priority-scheduling`。页面分析、评分和实际选号共用账号管理的账号性能数据。开关和权重仍保存在 `priority_scheduling_v1`，默认关闭，无数据库迁移。

## 数据来源

| 指标 | 读取来源 | 范围 |
| --- | --- | --- |
| 平均 TPS | 账号性能 `avg_tps` | 账号内全部模型和分组，沿用全局账号性能窗口 |
| 探针轮次降智率 | 账号性能 `degradation_percent` | 已完成且有明确结论的质量探针轮次 |
| 首字平均值 | 账号性能 `avg_ttft_ms` | 有唯一完整成功计时证据的流式文本请求 |
| 上游 HTTP 错误率 | 账号性能 `upstream_error` | 当前进程已观测 HTTP 4xx/5xx 响应 ÷ 已观测响应；重试单独计数 |
| 利润 / 成本 | `usage_logs` | 所选公开模型、分组、用量窗口；保留请求推理档的财务范围 |

性能统计直接调用账号性能的读取函数，不另写质量、TPS、首字或错误率聚合。前端直接使用 `AccountPerformanceCell`，包括本进程覆盖、样本窗口与缺失值说明；不再并列显示旧分位数面板。全局性能周期由账号性能设置控制，页面的“利润用量窗口”只改变财务统计。

上游 HTTP 指标不覆盖原生 WebSocket、HTTP 200 流内业务失败或未收到 HTTP 响应的网络失败。缺数据与实际 0% 区分，不将没有证据解释为健康；账号性能窗口可能尚不完整。页面和实际选号所在进程不同、读取时刻不同或调度缓存未刷新时，HTTP 样本及评分可能暂时不同。

## 评分与实际选号

四项权重依次为探针质量、首字平均值、平均 TPS、利润 / 成本。预设权重保持原数值，自定义的旧 `load_weight` 数值改用于 TPS；不再以并发余量作为这一加权项。

- 质量因子：`1 - degradation_percent / 100`，使用原质量目标判断是否达标。
- 延迟因子：`1 / (1 + avg_ttft_ms / target_ttft_ms)`。
- TPS 因子：`avg_tps / (avg_tps + target_tps)`；目标默认 30 token/s，可修改。达到目标对应因子 0.5。
- 财务因子：用户扣费 /（用户扣费 + 理论成本）。理论成本沿用账号成本倍率，亏损仍为风险；API Key 缺财务样本时沿用成本倍率估算。
- 总分：上述因子的加权平均 × 100，再乘 `max(0.1, 1 - error_rate_weight / 100 × 上游 HTTP 错误率)`。错误权重为 0 关闭此惩罚；没有 HTTP 样本时不追加惩罚。

TPS、首字及利润沿用最小样本要求；未知性能保持中性因子并标记数据不足。首字均值超过目标时降级；停止模式沿用现有健康池优先及有界兜底，窗口均值恢复后解除延迟限制，不再依据独立坏样本时间制造惩罚到期或恢复期。

账号资格、实时并发槽、RPM、配额、已有会话归属、不可迁移续接、账号暂停及利润硬门槛继续生效。真实容量仍参与容量分档和原子准入。页面只读分析没有实时槽位，因此展示的估算权重不是最终分流概率。

实际选号沿用有界异步历史读取及缓存，不在每个业务请求中同步跑统计 SQL。刷新失败沿用原有缓存有效期与降级规则。页面每 30 秒刷新，隐藏页暂停，切换范围或退出时取消旧请求。性能查询失败不会伪造一批零指标。

## 默认分组与操作

首次进入优先选配置中仍在可选列表内的分组；否则选名称含 GPT 的首个启用 OpenAI 分组，再回退首个启用 OpenAI 分组。均不存在时显示未分组。加载匹配分组的模型目录后才发首次分析请求，不修改保存的调度范围。

手动选择未分组后刷新会保留选择。未分组仅指没有绑定分组的账号，不是全部分组。默认分组并不保证有当前模型的候选或样本。

“重算最近实际选号”针对最近实际请求的固定候选快照；不会覆盖当前选择的分析范围。清理粘性仍需明确确认并回读快照身份，不会自动修改账号或迁移固定续接。

## 兼容与回滚

旧配置中的分位数、延迟测量方式、质量时效、独立错误窗口/先验和惩罚分钟字段暂保留读取兼容，新评分不再使用，页面不再展示。旧客户端应升级后使用新的 `performance` 字段；旧分位数不能解释成均值。原独立协议尝试采集仍供其他传输诊断使用，不再作为优先调度评分源。

升级会改变已启用优先调度的评分口径：账号性能跨模型/分组汇总，TPS 替代原并发权重，平均首字替代分位数，错误权重为零时关闭错误惩罚。回退二进制恢复旧评分；本改动无数据迁移，不修改账号监控阈值或用户账本。PR 合并不代表已发布或部署。

管理员提示 ID 为 `priority-account-performance-scoring-initial-announcement`，用于页面标题和 TPS 目标字段。两处共享关闭状态，沿用按管理员、浏览器保存的现有新功能提示机制。
