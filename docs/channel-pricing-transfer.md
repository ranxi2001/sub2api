# 渠道模型定价导入导出

进入「渠道管理 → 渠道定价」，可直接在列表操作：

- 每行「复制定价」创建一份独立草稿，仅复制模型定价。检查名称、为各平台选择分组并保存后才创建新渠道。
- 每行「导出定价」导出该渠道全部平台的模型定价。顶部「导出当前页定价」只包含当前页；勾选后变为「导出所选定价」，包含跨页保留的已选渠道。搜索或切换状态筛选会清空选择。
- 顶部「导入定价」接受单平台、单渠道或多渠道 JSON，验证完整个文件后打开创建草稿。多渠道文件逐份检查并保存，取消会终止剩余导入；已保存的渠道保留。
- 勾选后显示批量操作条，可批量编辑或「导入到所选渠道」。独立单渠道 bundle 和旧单平台文件可作为共同定价模板；collection 集合即使只有一个渠道，也必须与所选渠道按名称一一匹配，重复名称、缺失或额外渠道均拒绝导入。确认提交前不会修改已保存渠道。
- 批量编辑仅更新勾选字段；定价替换仅影响模板包含的平台，保留目标渠道其他平台的价格。分组、模型映射和账号统计规则保持原配置。逐渠道显示成功和失败，部分失败时仅重试失败项。

列表导出的文件包含渠道名称和模型定价，不含分组、模型映射、账号统计规则或功能开关。价格草稿需重新选择分组；批量修改已有渠道无需重新绑定。

原有的「创建/编辑渠道 → 平台标签 → 模型定价」仍提供单平台导入导出：

- 导出当前表单中的模型定价，包含尚未保存的修改；空列表可导出作模板。
- 导入本页导出的 JSON 文件，平台必须一致。确认替换后仅更新当前平台的模型定价，取消不会修改表单；检查后保存渠道才会写入。
- 包含默认价格、Token/按次/图片/视频计费模式、阶梯价格与倍率、Fast/Flex 倍率、思考等级倍率、时间段定价。文件不含渠道名称、分组绑定、模型映射、账号统计定价规则及其开关。
- 价格为空表示沿用原有默认价格逻辑；0 表示显式零价。Token 价格（含阶梯和图片 Token 价格）使用美元/百万 Token；按次/图片价格使用美元/次，视频价格使用美元/秒；倍率不换算。
- 导入会检查格式版本、单位、平台、非负有限价格、正倍率、模型冲突、阶梯与时间段规则。未知字段拒绝导入，避免把其他版本的字段静默丢弃。
- 文件限制为 2 MiB、1000 条定价规则、5000 个模型。不要将后端 per-token API 响应直接当作导入文件。

原单平台格式使用 `format: "sub2api-channel-pricing"`、`version: 1`、`platform`、`price_unit: "USD_per_million_tokens"` 和 `model_pricing` 数组，继续兼容。

列表单渠道格式为 `sub2api-channel-pricing-bundle`，包含 `name`、`platforms: [{ platform, model_pricing }]`；多渠道格式为 `sub2api-channel-pricing-collection`，`channels` 中包含完整的单渠道文件。两种格式均使用 `version: 1` 与 `price_unit: "USD_per_million_tokens"`。整个文件合计最多 2 MiB、1000 条定价规则、5000 个模型；集合最多包含 100 个渠道。

优先从页面导出再编辑，避免手工遗漏阶梯和时间段结构。列表格式由列表入口读取；编辑弹窗的单平台入口仍只接受原单平台文件。
