# 渠道模型定价导入导出

进入「渠道管理 → 创建/编辑渠道」，启用对应平台，在「模型定价」右侧选择「导出定价」或「导入定价」。

- 导出当前表单中的模型定价，包含尚未保存的修改；空列表可导出作模板。
- 导入本页导出的 JSON 文件，平台必须一致。确认替换后仅更新当前平台的模型定价，取消不会修改表单；检查后保存渠道才会写入。
- 包含默认价格、Token/按次/图片/视频计费模式、阶梯价格与倍率、Fast/Flex 倍率、思考等级倍率、时间段定价。文件不含渠道名称、分组绑定、模型映射、账号统计定价规则及其开关。
- 价格为空表示沿用原有默认价格逻辑；0 表示显式零价。Token 价格（含阶梯和图片 Token 价格）使用美元/百万 Token；按次/图片价格使用美元/次，视频价格使用美元/秒；倍率不换算。
- 导入会检查格式版本、单位、平台、非负有限价格、正倍率、模型冲突、阶梯与时间段规则。未知字段拒绝导入，避免把其他版本的字段静默丢弃。
- 文件限制为 2 MiB、1000 条定价规则、5000 个模型。不要将后端 per-token API 响应直接当作导入文件。

文件格式使用 `format: "sub2api-channel-pricing"`、`version: 1`、`platform`、`price_unit: "USD_per_million_tokens"` 和 `model_pricing` 数组。优先从页面导出再编辑，避免手工遗漏阶梯和时间段结构。
