# 鹈鹕随机题库

账号页的测智弹窗中选择鹈鹕题型，再选择“随机题库（同轮共用）”。准备题目只调用本站管理接口，不请求模型。点击开始测试仍会按原流程请求上游。

在同一浏览器标签页、同一管理员会话中，切换到另一个账号后选择随机模式，会复用刚才准备的轮次。所有并行样本也复用该题目。点击“准备下一轮”重新抽题；随机抽取允许重复，不承诺每轮题目不同。刷新页面后需要重新准备手动轮次。

账号定时规则与鹈鹕展示页的分组定时编辑器都提供相同模式选项。自动执行按原定执行时间（UTC 时间点）确定题目；原定时间相同的规则使用同一道题，延迟执行或不同副本不改变选题。手动立即执行分组规则以该次运行时间建立独立轮次。

题库包含难度结构相近的 SVG 循环动画题，版本为 `svg-motion-v1`。题目有独立的人工复核判据；传输成功不代表模型绘图质量合格。没有新增自动判题、付费探测、重试或并发上限。

结果保留题目 ID、版本、轮次、来源、题干、实际提示词和判据。账号测智记录详情及分组测试预览可查看快照；编辑当前规则不会重写历史。手动历史仍只保存在当前浏览器，定时历史仍保存在现有结果 JSON 中。

缺少 `prompt_mode` 的旧规则继续执行原自定义题面。新功能默认保持自定义模式，管理员主动选择随机模式后才启用。旧记录或自定义题目没有题库元数据时显示明确说明，不补造版本或判据。

本次没有数据库迁移。回滚到不支持随机模式的二进制前，应将随机规则改回自定义模式并填入题面，或先暂停这些规则；旧二进制忽略新增 JSON 字段，不能继续保证随机选题。题库版本升级后，旧的手动轮次可能被服务器拒绝，应重新准备一轮；历史快照仍用于查看。

管理员提示 ID 为 `pelican-random-question-bank`，用于手动模式、账号定时新增/编辑及分组定时新增/编辑入口。在任一入口关闭后，同一浏览器同一管理员的其他入口同步隐藏；隐藏状态沿用现有 localStorage 机制。
