# 密钥安全巡检

后台密钥巡检默认启用观察，超龄提醒、自动风险邮件均默认关闭。管理入口为 **管理后台 → IP 审计 → 密钥风险**。无需修改客户端协议。后台巡检不自动删除账号或吊销密钥；管理员可以为单个 Key 配置来源白名单，由现有鉴权阶段实时拒绝其他来源。

## 设置与规则

- 建议轮换时间默认 90 天，依据 `api_keys.created_at`，不依据最后使用时间。不自动让旧 key 失效；用户先创建新 key、更新客户端，再停用旧 key。
- 默认检测窗口 30 分钟，可设 1–60 分钟。
- 以单个 Key 为检测主体，默认在窗口内出现至少 **2 个不同 IP** 时生成 `key_ip_spread` 风险。同 IP 下多个用户使用各自的 Key、同一用户用不同 Key 访问不同 IP，均不因此告警。
- 开启自动风险邮件后，单 Key 跨 IP 记录即可通知该 Key 的所有者，不再依赖其他用户或跨用户 IP。邮件仍遵守次数上限、客户暂停和每用户 24 小时去重。
- IPv4 mapped IPv6 和等价 IPv6 地址归一化去重。可信出口支持 IP / CIDR，仅全部来源均可信时免告警；一个可信出口加一个未知来源仍会检测。
- Key 已配置 IP 白名单，且窗口内全部来源均被白名单允许时，不生成新的跨 IP 告警；Key 黑名单仍优先。配置白名单不自动解决已有事件，核实后可标记解决。
- 未知、未鉴权来源不会被归入某个用户。地理位置、UA、轮询间隔不单独用于认定泄露。

跨 IP 是待核查信号，不等同于已泄露。需要允许办公、家庭或多个服务出口时，为该 Key 明确配置允许的 IP/CIDR。共享同一 IP 的团队使用不再视为独立密钥风险。

## 管理操作

风险记录包含规则、IP / key ID、关联用户和 key、窗口请求数、IP 列表、首次及最近命中时间。首次时间为首次发现时的窗口起点，并非全站历史首次请求时间。支持忽略、解决、重新打开。“忽略”状态由管理员重新打开；“已解决”记录遇到解决时间之后的新请求，或新增来源 IP / 用户 / key 证据，会自动进入下一代事件并重新打开。重复扫描原窗口不会重新打开。

“通知关联用户”需要确认，生成持久化任务。收件人为账号邮箱；排队时持久化事件代次、密钥集合和证据快照；发送时仅重新验证这些密钥的归属和有效性，不受后续窗口覆盖影响，绝不把其他用户的密钥、邮箱或完整密钥值写入邮件。每封最多列出 50 个 key。忽略、解决、删除或停用 key 后，没有剩余关联有效 key 的任务将跳过。

“限制此 Key 来源”需要管理员填写并确认非空的允许 IP/CIDR 列表，替换该 Key 的现有 IP 白名单。操作绑定当前风险事件代次，拒绝已解决事件、已停用/删除/过期 Key、归属变更和旧代次。复用 APIKeyService 更新及鉴权缓存失效，不更改 Key 黑名单、额度、用量或其他字段。后续鉴权拒绝未允许来源（HTTP 403）；不依赖 IP 风控总开关或观察模式，不中断已经开始的请求。用户仍可通过自己的 Key 编辑页维护/清空该白名单；这是现有可由所有者编辑的来源限制，不新增管理员锁定策略。

密钥风险页已移除“加入 IP 黑名单”操作，旧客户端提交 `block` 会被拒绝，避免影响共享出口上的其他正常 Key。管理员操作通过已有审计中间件记录。

## 后台成本和覆盖边界

- 仅完整应用节点启动；gateway 节点不启动。不在 API 鉴权、转发或计费路径增加查询、邮件或网络调用；来源限制复用原有 Key IP ACL 检查。
- 使用独立连接池，最多 2 个数据库连接、1 个空闲连接。
- 每分钟扫描最近窗口，利用现有用量时间索引重叠扫描，包含已经落库的延迟写入；并非完整历史回放或按 ID 水位增量消费。窗口外才落库的记录可能漏检。
- 每次最多读取 10001 条计费用量，超过 10000 条仅生成有限样本风险，页面显示覆盖不完整，并禁止该轮自动风险邮件。高流量站点需要后续采用独立增量聚合表；不要盲目调高上限。
- 单次巡检预算 40 秒，扫描事务每条 SQL 超时 5 秒，使用事务级 advisory lock 防止多节点重复扫描。通知 claim 使用 `FOR UPDATE SKIP LOCKED`，无进程内大队列。
- 每轮最多新增 100 个用户的年龄提醒，发送最多 10 封邮件。每用户风险通知 24 小时内合并，年龄通知 30 天内合并，唯一约束与扫描/手动通知的共享事务锁防止重复排队。
- 邮件尚未发送时会检查总开关和相关自动通知开关；手动风险邮件不要求开启自动邮件。任务保存在 PostgreSQL，重启不丢失；同用户尚未发送的通知会合并新选中的密钥证据。
- 发送准备阶段在持有任务行锁的数据库事务中完成，用户 / 密钥查询失败、上下文超时或进程崩溃会回滚到待发送，下一轮可重试；准备成功提交后才进入 `sending`。
- SMTP 错误可能表示邮件已被服务器接受。发送失败或发送中崩溃超过 10 分钟的任务标记 `uncertain`，不自动重发，防止邮件轰炸；成功、排队、不确定计数显示在页面。这里不提供“确保送达”的承诺。
- 已处理风险及其通知尝试、客户确认记录保留至少 365 天（自最近风险、管理操作、发送尝试或确认时间计算）；终态发送队列保留至少 90 天。后台每次最多清理各 100 条，未处理风险不会自动删除。

当前信号来源是 `usage_logs`，**不包含 `/v1/usage` 轮询、鉴权失败或没有生成用量的请求**。现有 connection traces 是可丢弃诊断队列，未当成完整安全证据。覆盖这些请求需要后续独立、可监控的异步鉴权事件采集，不能把当前页面当成完整入侵检测系统。

## 提醒上限与客户确认

- 管理后台可设置 `max_reminders`，默认 3 次，范围 1–10。按“风险事件 + 事件代次 + 用户”计算，手动和自动风险邮件共同遵守。旧配置缺少此字段时使用默认 3 次；超龄轮换提醒不受此风险邮件上限影响。
- 计数在进入发送阶段时持久化，`sending`、`sent`、`uncertain` 都占用一次，准备失败及跳过不计数。此处是尝试次数，不是送达次数。相同用户实际风险发送尝试间隔至少 24 小时，队列延迟不能绕过该限制。
- 客户登录后，在 **API 密钥 → 密钥风险提醒** 查看自己的相关 Key ID、异常规则、提醒尝试次数。点击 **我已知晓，暂停本次提醒** 后，还需二次确认；登录身份决定所属用户，不能替他人确认，也不能用旧事件代次确认新事件。
- 客户确认记录与管理员“已解决”状态独立。确认只停止该用户、本事件、本代次的后续风险邮件，不停用 Key、不解除封禁、不关闭共享风险，也不代表泄露已消除。正在 SMTP 发送的邮件无法撤回；尚未开始发送的邮件在准备时检查确认状态。
- 已解决事件出现新证据并进入下一代事件时，旧确认和旧次数不再抑制新事件；同一代持续异常仍遵守既有暂停选择。管理员仅手动重新打开原事件，不会清除客户确认。
- 后台风险行的“通知与客户确认记录”展示各代次、用户、尝试/已提交/待定或不确定次数、最近尝试与确认时间。客户页面不返回其他用户、邮箱、完整 Key 值或共享 IP 证据。
- 迁移 336 新增独立收件人状态和发送记录，发送队列清理或进程重启不会重置上限。确认时保留用户自己的密钥集合、规则、证据末次时间及提示版本快照；重复确认不改写原时间或快照。历史迁移只能回填仍保留的发送任务与证据，旧版本已清理的数据无法恢复。
- 通知状态仅证明系统记录的发送尝试/提交结果，客户主动确认另行记载，不把 SMTP 成功等同于客户收悉或阅读，不自动作法律责任判断。
- 管理员手动通知返回实际排队/合并人数；被确认、次数上限或去重规则抑制时，页面明确提示未新增通知。

## 单 Key 跨 IP 规则升级

迁移 `342_key_risk_per_key_ip.sql` 将未设置或仍为旧默认值 5 的 `ips_per_key` 更新为 2；其他显式数值保留。无法区分人为选择的 5 与旧默认 5，需要保留 5 的站点请升级后重新保存。移除不再使用的 `users_per_ip` 配置。旧请求携带该字段不会恢复已停用规则。

`cross_user_ip`、`key_ip_spread_linked` 的待处理事件标记为已解决，原事件、证据、邮件尝试和客户确认记录保留在后台。客户提醒列表隐藏这两类旧规则。纯旧规则待发队列标记跳过，混合队列保留有效单 Key 事件；发送准备阶段也按规则过滤，不能通过旧 API 手动通知或重新打开旧规则。已经进入 SMTP 的邮件无法撤回；迁移不自动重发或修改发送中任务。

回退旧二进制不会撤销这次配置和事件状态更新；先备份，若回退需另行核查配置。不会自动删除之前人工添加的全局 IP 黑名单，管理员应核查其原始理由后按现有入口解除。

新功能提示 ID：`key-risk-per-key-source-restriction-initial-announcement`。展示于 IP 审计“密钥风险”页签及当前风险行的“限制此 Key 来源”，共用同一 ID；关闭任一入口后同步隐藏，沿用当前管理员、当前浏览器 localStorage 持久化。原密钥提醒提示 ID 保留，不重置其关闭记录。

客户端 IP 判定沿用现有可信代理/转发头设置。部署时需确保来源链配置准确；当前巡检仍读取用量元数据，不将其作为自动选择“安全 IP”的依据，管理员必须自行核实允许的出口。本次不引入首次 IP 自动绑定或自动封禁。
